In this project you should replace my .mp3 file on line 8 with the name of YOUR .mp3 file (or any of Librosa's songfiles' accepted file types).

This program detects the key of a song according to two metrics: the song's notes and the song's chords.

It uses STFT feature extraction to separate frequencies into 12 bins, each one called a "chroma" and representing each note (C, C#, D, D#, E, etc.)

Achieved an 80% success rate in detecting the key of 15 sample songs, including:
  "8 (circle)" by Bon Iver (by chords)
  "Cayendo" by Frank Ocean (by notes)
  "Earrings" by Malcolm Todd
  "Out Of My League" by Fitz and the Tantrums
  "The Party (Single)" by Portraits Of Tracy
